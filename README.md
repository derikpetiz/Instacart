Instacart — Análise de Dados e Comportamento de Clientes. Projeto desenvolvido durante o MBA em Data Science & Artificial Intelligence, utilizando Python e Pandas para explorar pedidos e comportamento de clientes. Inclui limpeza e tratamento de dados, análise exploratória, identificação de padrões de recompra e insights de produtos mais relevantes, gerando informações para apoiar decisões de negócio. Tecnologias: Python, Pandas, Análise Exploratória de Dados, Manipulação de Dados, Estatística, Visualização de Dados. Objetivo profissional: demonstrar aplicação de dados em problemas reais de negócio e análise de comportamento de clientes.
